# cody-tgbot

Ваш личный Codex на сервере, доступный через Telegram

`cody-tgbot` превращает Telegram в удобный интерфейс для настоящего Codex, работающего на вашем Linux-сервере.

Под удобным Telegram-интерфейсом работает Codex app server — с его диалогами, инструментами, файлами, моделями и доступом к рабочей папке.

Агента зовут Коди.

## Зачем

Коди постоянно живёт на вашем сервере, поэтому обращаться к Codex можно в любой момент прямо из Telegram.

Отправьте сообщение, голосовое, скриншот, фотографию или документ. Коди изучит проект, изменит файлы, запустит инструменты и вернёт результат в тот же чат.

Всё происходит в привычном и удобном интерфейсе Telegram — без отдельных панелей управления и удалённого рабочего стола.

## Принципы

**Настоящий Codex.** Коди создаёт удобный Telegram-интерфейс вокруг Codex, сохраняя его инструменты, модели, рассуждения и возможности работы с кодом.

**Ваш сервер и ваши данные.** Проекты, файлы, память, очередь задач, автоматизации и авторизация остаются под вашим контролем.

**Общение обычными сообщениями.** Большинство действий выполняется через естественный разговор. Настройки и управление аккуратно собраны в небольшом inline-меню.

**Проекты появляются из работы.** Можно сразу рассказать Коди, что хочется сделать. Когда идея превращается в настоящий продукт, Коди сохранит его как проект вместе с важными решениями и контекстом.

**Вся суть — в простом интерфейсе.** Коди делает возможности Codex удобными в Telegram, не заставляя разбираться во внутренней технической механике.

## Возможности

- потоковые ответы Codex в Telegram;
- живое сообщение с комментариями и работой инструментов;
- несколько диалогов Codex с быстрым переключением;
- текст, голосовые, фотографии, документы, альбомы и статичные стикеры;
- очередь запросов и добавление сообщения в активную задачу;
- остановка текущей задачи;
- восстановление работы после перезапуска;
- карточки проектов с памятью и иллюстрациями;
- обсуждение проекта в новом независимом диалоге;
- автоматизации, привязанные к проектам;
- модели, рассуждения, аккаунт, состояние и лимиты Codex в настройках;
- авторизация через подписку ChatGPT/Codex или API-ключ;
- доступ только для разрешённых Telegram-пользователей.

Голос распознаётся через Codex Dictation. Локальный faster-whisper используется как резервный вариант.

## Проекты и автоматизации

Проект хранит рабочую папку, описание, текущее состояние, важные решения и ограниченную память.

Диалоги не прикрепляются к проектам навсегда. Кнопка «Обсудить проект» создаёт обычный новый диалог и один раз добавляет в него актуальный контекст проекта.

Каждая автоматизация принадлежит проекту. Она может запускаться один раз, по интервалу или cron-расписанию. Работа выполняется в отдельной сессии Codex и не мешает активному диалогу.

Очередь, незавершённые задачи и автоматизации сохраняются на диске и переживают перезапуск процесса.

## Установка

Требования:

- Linux;
- Node.js 20 или новее;
- Telegram-бот от BotFather;
- подписка ChatGPT/Codex или OpenAI API-ключ.

```bash
git clone https://github.com/tumanov-git/cody-tgbot.git
cd cody-tgbot
npm install
cp .env.example .env
```

Минимальная конфигурация:

```env
TELEGRAM_BOT_TOKEN=...
TELEGRAM_ALLOWED_USER_IDS=...
APPROVED_DIRECTORY=./workspaces
```

Сборка и запуск:

```bash
npm run build
npm start
```

Для разработки и проверки:

```bash
npm run dev
npm test
```

Для постоянной работы рекомендуется запуск через systemd или другой менеджер процессов.

## Авторизация Codex

Если оставить `CODEX_API_KEY` пустым, владелец сможет подключить подписку ChatGPT/Codex через `Меню → Настройки → Аккаунт`.

Также можно задать API-ключ на сервере:

```env
CODEX_API_KEY=...
```

Первый пользователь из `TELEGRAM_ALLOWED_USER_IDS` считается владельцем установки. При необходимости его можно указать отдельно через `TELEGRAM_OWNER_USER_ID`.

## Основные настройки

```env
CODEX_MODEL=
CODEX_AUTOMATION_MODEL=
CODEX_SANDBOX_MODE=workspace-write
CODEX_APPROVAL_POLICY=never

APPROVED_DIRECTORY=./workspaces
MAX_PARALLEL_CODEX_TASKS=2

CODY_TIMEZONE=Europe/Moscow
MAX_ACTIVE_AUTOMATIONS=20
MAX_PARALLEL_AUTOMATIONS=2
```

Полный список находится в `.env.example`. Локальные данные Коди хранятся в `.cody-tgbot/` и не должны попадать в Git.

## Безопасность

Коди получает настоящий доступ к серверу, поэтому использовать его могут только Telegram-пользователи из `TELEGRAM_ALLOWED_USER_IDS`.

Границы рабочих папок и разрешения Codex задаются через переменные окружения. Не добавляйте в репозиторий `.env`, токены, данные авторизации и папку `.cody-tgbot/`.
